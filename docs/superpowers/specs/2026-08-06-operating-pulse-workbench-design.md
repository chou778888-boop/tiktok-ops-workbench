# 经营脉冲工作台设计规格

日期：2026-08-06
状态：方向 A 已确认
范围：全局工作台外壳、总览首屏、利润焦点入口；既有业务页面与利润计算保持不变

## 1. 设计判断

现有“固定左侧导航 + KPI 横排 + 白色面板网格”属于常见 ERP 语法。继续优化配色、阴影和圆角只能得到更精致的 ERP，无法形成产品独特性。

新方向以“经营脉冲”为产品识别：团队进入工作台后，不先选择模块，而是先看到今天最值得处理的产品链接、近七天价格与动销信号、数据同步节奏以及可直接执行的动作。

## 2. 核心目标

- 首屏 10 秒内回答：今天先处理哪条链接、为什么、影响多少、下一步做什么。
- 把多店铺 → 产品 → 链接 → SKU 的真实业务层级变成首屏主线。
- 默认观察近 7 天；只有已同步的日期显示真实价格和销量，其余日期明确标为待同步。
- 成交均价、实际到手、成本和利润继续保持独立口径。
- 保留日报、任务、达人、学院、数据管理、利润与成本的所有入口和功能。

## 3. 独特视觉语法

### 3.1 顶部经营坞

- 桌面端移除固定左侧栏，改为横向、轻量、悬浮的顶部经营坞。
- 品牌、一级导航、同步状态和高频动作在同一条信息线上完成。
- 导航不使用大块选中背景；通过精细指示、字体层级和局部高亮表达状态。
- 1180px 以下自然换行，760px 以下主导航横向滚动，不遮挡主要操作。

### 3.2 编辑式首屏

- 左侧使用大标题“今天，先处理这一条。”建立明确决策入口。
- 右侧保留日期范围，但降低其视觉权重。
- 标题不装入普通卡片；依靠留白、栅格和细分隔线建立层级。

### 3.3 荧光经营焦点

- 使用单一半透明荧光绿焦点面，展示当前最高优先级的产品/链接结论。
- 焦点面必须来自利润仓库与选择器的真实数据，不写死展示值。
- 展示产品、店铺、链接、SKU 数量的完整路径，并提供“处理此链接”主动作。
- 若没有可用利润数据，显示数据形成条件和进入利润页的下一步，而不是虚构异常。

### 3.4 七天经营脉冲

- 同一画布中表达成交均价折线、销量柱和经营日期。
- 只强调已同步点；待同步日期保留在时间轴上但不绘制虚假数值。
- 下方直接显示近 7 天销量、GMV、实际/预估到手与利润。
- 同步节奏明确呈现：16:00 店铺更新、17:00 工作台同步、异常判断、团队处理。

### 3.5 次级内容

- 多店 GMV、来源结构、店铺总览和异常摘要保留在首屏之后。
- 次级区域降低卡片墙感：减少重复容器，使用连续画布、分隔线和不对称宽度。
- 利润页结构与计算不改，只通过顶部经营坞保持全局一致。

## 4. 数据与交互

- `makeOverviewPulseModel(productRows, attentionItems, activeDate)` 为纯函数，负责把利润选择器输出转换成首屏展示模型。
- 数据优先取销量最高的产品及其首条有效链接；动作优先取对应链接的待补费用、亏损、对账差异或观察事项。
- 主动作进入 `利润与成本` 的具体链接详情，不只进入利润总盘。
- 日期筛选继续控制多店总览；利润焦点使用利润工作区当前经营日期，并在文案中明确日期。
- 进入工作台时只执行一次短促分层出现动效；尊重 `prefers-reduced-motion`。

## 5. 响应式与排版

- 验证 1440px、1280px、760px 和约 320px 宽度。
- 中文标题使用平衡换行，不允许孤字或少字换行。
- 金额、销量、百分比使用等宽数字并按语义对齐。
- 窄屏按“结论 → 动作 → 趋势 → 指标 → 次级内容”排序，不机械缩小桌面画面。
- 页面整体不得横向溢出；只有表格和明确的横向导航可以局部滚动。

## 6. 技术边界

- 新增独立的首屏模型模块，避免把利润选择逻辑继续堆入 `10-overview.js`。
- 新视觉仍由令牌与最终级联模块控制，禁止修改 `dist/`。
- 不修改利润公式、仓库样例、结算口径、费用逻辑和同步数据。
- 不新增依赖、图片占位、装饰性 3D 或循环动画。
- 当前工作树包含其他未提交工作；只修改本规格明确列出的文件，不提交或覆盖无关改动。

## 7. 验收标准

- 桌面端不再出现固定左侧 ERP 导航。
- 首屏真实显示 JZZ 样例的 39 件、$675.52 GMV、$631.47 实际到手与 $163.47 暂算利润。
- “处理此链接”可进入 JZZ 主链接详情。
- 近七天脉冲只显示真实同步日，不补造数据。
- 所有现有检查、利润模型测试与构建通过。
- 同视口视觉对比确认首屏与已选方向 A 在信息层级、焦点材质和画面节奏上一致。

## 8. 自查结论

本规格覆盖用户确认的方向 A、团队效率、数据真实性、可维护性、中文排版和全局工作台一致性。实施范围被限制在外壳与总览入口，不触碰利润底层逻辑，也不以视觉重构为理由扩张业务范围。
