# 任务中心居中紧凑版设计

## 目标

解决宽屏下任务中心铺满屏幕、视觉重心偏左、两列任务卡过宽的问题，同时保持现有任务数据、状态流转和操作逻辑不变。

## 版式

- 任务中心内部使用独立居中容器，桌面最大宽度 1440px，左右自动留白。
- 标题区、视图切换、身份摘要、统计和任务列表共用同一内容边界。
- 桌面任务列表为三列；中等屏幕为两列；移动端为单列。
- 团队任务按负责人分组，展开后的卡片采用同样的响应式列数。

## 视觉层级

- 标题与未完成数量保持同一行，缩短说明文字的视觉宽度。
- 视图切换改为居中的紧凑分段控件。
- 当前人员和三项统计整合成一块信息带，减少重复大面积卡片。
- 任务卡降低高度与空白，标题两行截断；状态置于右上；负责人、优先级和截止时间作为次级信息；操作按钮固定在卡片底部。
- 使用现有设计令牌、圆角和状态色，不引入新视觉体系。

## 响应式与交互

- ≥ 1280px：三列。
- 760–1279px：两列。
- < 760px：单列，身份与统计纵向排列。
- 展开详情、开始处理、提交结果、作废、筛选和历史加载逻辑保持原样。

## 验收标准

- 2048px 宽屏下内容明显居中，不贴左右边缘。
- 单张任务卡不再横跨半个超宽屏。
- 三列卡片之间间距一致，操作区对齐。
- Mac、Windows 与移动端无横向溢出。
- 原有任务中心测试与完整构建继续通过。
