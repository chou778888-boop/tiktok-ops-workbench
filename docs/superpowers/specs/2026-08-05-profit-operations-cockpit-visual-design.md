# 链接利润分析「专业运营驾驶舱」视觉升级设计

## 目标

在不改变产品 → 多店多链接 → 单链接 → SKU 四层结构和利润计算口径的前提下，把当前偏素、信息层级弱的利润模板升级为适合跨境电商团队日常操作的专业运营驾驶舱。

成功标准：运营进入页面后，能在 5 秒内判断整条链接是否赚钱、成交均价与销量是否同步变化、平台结算是否完成，以及下一步应处理哪个 SKU 或费用异常。

## 已确认方向

- 视觉方向：A「专业运营驾驶舱」。
- 基调：深墨绿、暖灰白、少量琥珀警示和克制的亏损红。
- 页面属性：团队操作台，不做展示型大屏；信息密度、快速扫描和长期使用舒适度优先。
- 趋势表达：成交均价使用折线，销量使用柱形，共享最近 7 天日期轴。

## 当前问题与确定性修正

### 1. 平台结算主指标出现异常黑色描边

结算主指标使用了通用类名 `primary`，与工作台全局主按钮样式发生冲突，导致移动端出现黑色粗边、超大圆角和内容错位。

修正：将该语义改为利润模块专属类名 `profit-settlement-primary`，所有视觉规则限定在利润模块内，避免再次受到全局样式污染。

### 2. 七天趋势只是数字条，无法快速判断变化关系

当前七列数字适合查值，但不适合判断“调价后销量是否提升”。

修正：新增独立的 `renderProfitTrendChart` 渲染器：

- 上层：成交均价折线，展示 7 个数据点、首尾值和当前日高亮。
- 下层：每日销量柱形，和成交均价共享日期轴。
- 关键摘要：7 日成交均价、日均销量、价格变化、销量变化。
- 图表数据直接来自现有 `sevenDay.days`，不复制业务计算。
- 图表保留可访问文本摘要；零销量、待同步、负利润等状态有明确降级表现。

SKU 展开趋势使用相同图表组件，但数据源改为单 SKU 的 `trend.points`，保证链接趋势与 SKU 趋势表达一致。

## 页面层级

### 产品总盘

- 同步状态由普通提示条升级为“数据新鲜度控制条”，突出最近同步、下次同步和数据来源。
- 四项总盘指标形成清晰层级：GMV、实际/预估到手、最终利润、销量。
- 最终利润使用墨绿强调，亏损才切换为红色；避免所有数字同等抢眼。
- 今日动作保留在右侧，使用优先级和状态色帮助团队快速处理。

### 产品整体

- 产品身份、统一成本和经营状态收敛在同一头部区域。
- 多链接卡片突出销量、成交均价、最终利润和当前结算状态。
- 同品不同店铺使用同一比较网格，避免视觉形式随链接变化。

### 单链接详情

阅读顺序固定为：

1. 链接身份和生命周期。
2. 当日五项核心指标。
3. 最近 7 天成交均价与销量趋势图。
4. 平台结算拆解。
5. SKU 成交与贡献。
6. 团队维护的广告和样品费用。

趋势图放在结算前，因为运营先判断经营变化，再进入财务对账。

## 视觉系统

- 页面底色：暖灰白，减少大面积纯白造成的“表格系统”感。
- 核心卡片：白色或轻微墨绿染色，使用 1px 低对比边框与柔和阴影建立层次。
- 强调色：墨绿只用于正向利润、当前数据点和主操作；不把所有装饰都染绿。
- 警示色：琥珀用于待同步、结算处理中和调价观察；红色只用于真实亏损或错误。
- 圆角：主容器 18–22px，内部卡片 12–16px；不使用胶囊形大容器包裹核心数字。
- 字体：保留工作台现有字体栈，强化中文标题、数字和辅助说明之间的字号与字重差。
- 数字：继续使用等宽数字特性，金额和数量右对齐，避免列间跳动。

## 交互与响应式

- 桌面端趋势图完整显示 7 天，无整页横向滚动。
- 手机端图表保持同一数据含义，压缩辅助文案但不隐藏当前日、价格线和销量柱。
- SKU 表在手机端继续切换为卡片，展开后直接显示紧凑趋势图。
- 所有按钮保留明确焦点态，但焦点样式只作用于可交互元素。
- 图表不依赖悬停才能理解；移动端和键盘用户均能读取关键摘要。

## 代码边界

- 业务模型和选择器保持不变，视觉层只消费其结果。
- 图表计算拆分为纯函数：点位、比例尺、路径和空状态可独立测试。
- 页面 HTML 仍由 `65-profit-template.js` 负责；利润视觉规则继续集中在 `18-profit-template.css`。
- 不引入新的前端框架或大型图表依赖，避免为 7 天固定窗口增加维护成本。
- 禁止使用通用类名承载利润模块专属样式，新增类统一使用 `profit-` 前缀。

## 验收

- 回归测试覆盖：趋势图语义、7 个日期点、当前日、待同步状态、结算专属类名和禁止通用 `primary`。
- 完整项目检查和生产构建通过。
- 浏览器验证三个流程：产品总盘 → 产品整体 → 单链接详情。
- 桌面 1440×900 与手机 390×844 均检查：无整页横向溢出、无异常描边、文字无孤字换行、图表数据可读。
- 浏览器控制台无与利润模板相关的 error 或 warning。

## 非本轮范围

- 不接入真实 TikTok/站斧数据同步。
- 不改变成交均价、实际到手、平台费用和最终利润公式。
- 不新增历史 30/90 天分析、预测模型或复杂图表筛选。
- 不重做工作台其他模块的视觉系统。
