# 日报填写区按岗位展开设计

## 目标

缩短日报中心的默认页面长度。进入日报中心时优先看到今日汇总和自动周报；只有明确选择岗位后，才展示该岗位的详细填写内容。

## 页面结构

“提交岗位日报”面板保留，并分为两个区域：

1. 基础栏始终显示：日报日期、日报类型、姓名 / 汇总人、最高风险、日报状态。
2. 详细填写区默认隐藏：岗位说明、今日工作导航、岗位今日结果、其他完成事项、待复查任务、经营闭环、保存回执、清空与提交按钮。

日报闭环流程条属于详细填写区，未选择岗位时不显示。详细填写区隐藏后，“自动周报”面板自然上移，用户无需滚过空表单。

## 岗位选择

- 日报类型增加空选项“请选择岗位”，首次进入默认选中空值。
- 选中售后组、BD、店铺维护、店群运营或其他后，详细填写区一次性展开，并渲染对应岗位字段。
- 岗位切换继续使用现有 `reportSchema(role)`、`renderReportRoleFields(role)` 和闭环字段逻辑，不改变日报数据结构。
- 未选择岗位时不调用具体岗位的字段收集或提交逻辑。

## 提交与恢复

- 保存成功后保持详细填写区展开，保留服务端确认后的当天内容，允许继续修改。
- 当前浏览器记录最后成功保存的“日期 + 岗位 + 规范化填写人 + 日报 ID”。
- 同一天刷新页面时，仅当本地记录日期为今天、填写人与当前浏览器的填写人一致，且云端 / 当前状态中仍存在对应日报时，自动选择岗位并载入该日报。
- 日期进入第二天后，本地恢复记录视为过期：岗位回到“请选择岗位”，详细填写区收起。
- 如果恢复记录缺失、损坏、日报不存在或填写人不匹配，安全降级为收起状态，不加载其他人的日报。
- 点击“日报记录”中的本人今日日报编辑按钮时，无论当前是否收起，都自动选择岗位、展开并回填现有内容。

## 清空行为

点击“清空”后：

- 清除当前表单值、编辑状态和当日恢复记录。
- 日期恢复为今天，岗位恢复为“请选择岗位”。
- 详细填写区收起，自动周报重新上移。

## 数据与安全边界

- 不修改日报、任务或周报的云端数据结构。
- 不改变日报唯一槽位、本人当日编辑、团队岗位汇总、防覆盖和任务同步规则。
- UI 恢复记录只写当前浏览器的 `localStorage`，不写入 D1。
- 部署不执行 D1 写入、迁移或初始化。

## 验收标准

- 首次进入时基础栏可见，岗位为空，详细填写区隐藏，自动周报直接跟随其后。
- 选择每个岗位后，详细填写区展开且字段与当前线上版本一致。
- 提交成功后保持展开，已保存内容仍可编辑。
- 同日刷新仅恢复当前浏览器最后成功保存且身份匹配的日报。
- 模拟次日或过期记录时自动收起。
- 编辑本人今日日报可从收起状态正确展开和回填。
- 清空后恢复到默认收起状态。
- 项目检查、语法检查、任务同步测试、专项测试、生产构建和桌面 / 移动端本地回归通过。
