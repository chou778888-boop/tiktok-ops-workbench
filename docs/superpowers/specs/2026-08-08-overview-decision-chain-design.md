# 总览经营决策链重构设计

## 目标

总览只保留一条清晰链路：整体经营结果 → 异常定位 → 链接下钻 → 负责人动作。消除连续展示两张近七日趋势图造成的重复体验。

## 信息架构

1. 顶部为整体经营判断，展示所选范围 GMV、订单、ROI、风险数量与最优先异常，不再默认放大单条链接。
2. 页面只保留一个主趋势区，默认展示多店 GMV 与来源贡献。
3. 主趋势区提供“多店 GMV”和“重点链接价量”两个互斥视图；切换时在同一位置替换图表和右侧解释，不新增第二张趋势图。
4. 重点链接视图展示成交均价、销量、实际到手、利润与处理动作；完整计算仍进入利润与成本模块。
5. 店铺表、产品表和异常摘要继续承担下钻与核对，不改变其数据和保存逻辑。

## 交互

- 日期筛选继续位于顶部控制栏并同时驱动整体判断、GMV趋势、店铺表、产品表和异常摘要。
- “多店 GMV”是每次进入总览的默认视图。
- 点击“重点链接价量”后，在同一趋势区域显示当前优先链接；处理按钮进入对应链接利润详情。
- 点击顶部“查看优先风险”滚动到异常摘要。
- 切换按钮必须有明确选中状态、键盘焦点和互斥的可见面板。

## 响应式

- 桌面端顶部判断采用结论与指标两列，主趋势区采用趋势与解释两列。
- 1180px 以下改为单列，不并排压缩长标题。
- 移动端趋势切换保持一行，图表和右侧解释依次排列，页面不得出现整体横向溢出。

## 验收

- 首屏不再同时出现“近7天成交均价与销量”和“近7日GMV”两张趋势图。
- 默认先看到公司级经营结果，单链接必须通过同一趋势区切换查看。
- 真实 7 天、多店、14 条 SKU 数据下无孤字、异常换行和页面级横向滚动。
- 今日、昨日、近7日、指定日期、趋势切换、处理链接和查看风险按钮均可真实点击。
