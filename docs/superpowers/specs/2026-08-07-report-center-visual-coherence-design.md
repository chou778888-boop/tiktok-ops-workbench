# 日报中心视觉协调与填写体验设计规格

## 目标

在不改变日报数据、岗位字段、保存流程、任务同步和周报逻辑的前提下，解决当前日报中心“顶部过重、左右像两套系统、卡片层级重复”的问题。新版必须兼顾主管快速判断与团队成员高频填写，让页面既有明确重点，也适合每天长时间使用。

本规格取代 `2026-08-06-report-center-original-flow-visual-refresh-design.md` 中的顶部双深色结构和等高假设，但保留岗位渐进展开与完整业务流程。

## 设计判断

当前不协调来自三个根因：

1. 顶部经营脉搏和左侧岗位覆盖同时使用大面积深色，形成重复视觉中心。
2. 左侧摘要内容较少，右侧表单内容密集，两栏缺少统一的标题、留白和表面规则。
3. “经营重点”以三张独立卡片插入表单，卡片套卡片，增加边框噪声并打断填写动线。

因此页面只保留一个强视觉中心，其余内容统一为安静、清晰、可填写的浅色工作表面。

## 页面结构

页面保持现有业务顺序：

1. 页面标题与日期筛选。
2. 团队经营脉搏。
3. 日报工作区：岗位覆盖与自动摘要、岗位日报填写。
4. 今日行动重点。
5. 自动周报与日报记录。

不移动自动周报、日报记录，不改变关键 DOM ID 和脚本渲染入口。

## 视觉与交互设计

### 唯一主视觉：团队经营脉搏

- 经营脉搏是页面唯一深墨绿色大表面。
- 高度压缩，四项指标横向排列，数字优先，说明文字控制在两行内。
- 不使用渐变、发光和装饰性动画；深色只表达页面最重要的经营总览。
- 标题、日期筛选与经营脉搏之间保持紧凑但清晰的层级。

### 日报工作区

- 桌面端采用 `34% / 66%` 双栏，左侧为经营上下文，右侧为填写主任务。
- 两栏都使用同一套白色表面、边框、圆角和阴影，避免视觉割裂。
- 左侧不强制与完整展开后的表单等高，只与基础填写区形成首屏平衡；岗位展开后自然向下延伸。
- 左侧“岗位覆盖”改为浅色信息模块，以数字和缺口说明为主，不再使用第二块深色卡片。
- 自动团队摘要与岗位覆盖合并在同一左栏容器内，以分隔线区分，减少独立卡片数量。

### 经营重点与填写表单

- “今日最重要结果、最高经营风险、当前待闭环”保留真实数据，但改为表单标题下方的一条三段式信息带。
- 信息带使用同一浅色底，三段之间用细分隔线；风险仅使用小面积语义色，不再形成三张独立卡。
- 基础字段仍按现有顺序展示：日期、岗位、汇总人、风险、状态。
- 选择岗位前显示简洁引导；选择岗位后继续使用现有 `#reportDetails` 渐进展开。
- 输入控件、标签、说明文字保持至少 12px；常用控件高度不低于 44px。

### 今日行动重点

- 桌面端保持四列，便于主管横向比较完成、异常、跟进与协作。
- 四列采用统一白色表面，只用顶部细色条和状态符号表达分类。
- 空状态降低高度；有内容时允许列内滚动，不推高其他空列。

## 视觉系统

- 颜色沿用现有深墨绿、白色、浅灰绿与语义风险色，不新增品牌色。
- 圆角统一到 14–18px；内部信息模块使用 10–12px 圆角。
- 阴影只用于主容器，内部模块不重复投影。
- 所有卡片使用一致的 1px 中性边框，强调通过层级和间距实现。
- 标题使用现有工作台字重；数字使用等宽数字；中文自然换行，不出现孤字和窄列强制换行。

## 响应式

- `> 1080px`：经营脉搏四列；日报工作区 34/66 双栏；行动重点四列。
- `761–1080px`：日报工作区单列；左侧上下文内部可并排，填写区随后展示；行动重点两列。
- `<= 760px`：所有主区单列；经营脉搏两列；经营重点信息带纵向排列；基础字段单列。
- `<= 380px`：经营脉搏单列，保证说明文字完整；页面不得产生横向滚动。

## 技术边界

- 只调整日报中心结构样式及必要的语义包装，不改变日报业务模型和数据口径。
- 保留 `reportMetrics`、`reportProgress`、`dailyDigest`、`reportPrioritySignals`、`reportForm`、`reportDetails` 和 `dailyManagementBoard` 等关键 ID。
- 样式继续由 `src/styles/modules/20-report-command-center.css` 单点管理，消费现有设计变量，不向其他模块散落覆盖规则。
- 真实经营重点继续由现有日报、店铺 SPS 和任务数据派生，不使用静态示例。

## 验收标准

1. 页面只存在一个大面积深色主视觉，首屏没有重复视觉中心。
2. 左右工作区使用同一套表面语言，左侧不再显得孤立或空洞。
3. 经营重点不再表现为三张嵌套卡片，填写动线连续。
4. 1440px 首屏能同时看到经营脉搏、上下文摘要、经营重点和基础表单。
5. 320px、390px、760px、1080px、1440px 均无页面级横向溢出。
6. 选择岗位后详细字段正常展开，保存、任务同步、周报与历史记录逻辑不变。
7. 日报专项测试、完整项目检查和生产构建全部通过。

## 非目标

- 不重做日报业务流程或指标定义。
- 不调整任务中心、利润中心和总览页面。
- 不引入新的前端框架、图标库或动效系统。
- 不部署云端；先交付本地预览供用户确认。
