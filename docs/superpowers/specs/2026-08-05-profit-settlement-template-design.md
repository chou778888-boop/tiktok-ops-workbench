# 链接利润与结算模板设计

## 目标

在现有 TikTok 经营工作台内提供一套可交互的利润模板，让团队先判断产品整体，再比较同品在不同店铺的链接表现，最后下钻到单条链接的 SKU 成交均价、销量、贡献利润和七天趋势。

本轮只实现前端模板和演示数据，不接战斧自动同步、不写云端状态。所有字段名称、数据关系和状态必须与已经验证的 TikTok Shop 商品分析及结算明细兼容，后续接入时不重做页面结构。

## 核心原则

- 产品是经营决策的第一层，同一产品可包含多个店铺、多个链接和多个共同 SKU。
- 链接是利润核算的主体；广告费和样品费按“店铺 + 链接 + 日期”填写。
- SKU 用于动销和定价判断，不把链接共同费用强行分摊到 SKU，避免制造虚假精度。
- 产品成本在产品主档统一维护，并按生效日期形成历史快照；同一产品的所有 SKU、店铺和链接默认共用。
- 商品分析与结算是两个时间阶段：当天展示预估，平台结算后展示实际。
- 默认展示最近七天，更早历史收起；异常和待处理动作优先。

## 数据口径

### SKU 日事实

- `gmv`：平台 SKU 日 GMV。
- `itemsSold`：实际售出件数。
- `averageTransactionPrice`：`gmv / itemsSold`，没有销量时为空。
- `grossSales`：平台标价口径，仅作参考，不参与实际到手计算。
- `productCost`：产品成本快照。
- `contributionProfit`：SKU 经营贡献，模板阶段按预估到手减销量成本计算。

### 链接日结算

- `netSales`：结算详情中的净销售额。
- `shippingFee`：TikTok Shop shipping fee 等运费扣项。
- `platformFees`：平台各项费用合计。
- `settlementAmount`：平台 Total settlement amount，结算完成后作为真实到手金额。
- `settlementStatus`：`estimated`、`processing` 或 `settled`。
- `advertisingSpend`、`sampleSpend`：团队按链接和日期维护。
- `finalProfit`：`settlementAmount - 销量成本 - advertisingSpend - sampleSpend`；未结算时使用预估到手并明确标注“预估”。

### 对账规则

- 产品和链接总 GMV以平台汇总值为准，不直接用可能存在取整差异的 SKU GMV 相加覆盖。
- 保存 `reconciliationDifference = listingGmv - sum(skuGmv)` 并在有差异时提示。
- 结算通过 `shopId + orderId + skuId` 关联经营数据。
- 结算未完成不覆盖历史预估；完成后保留预估值与最终值，便于复盘误差。

## 信息架构

### 产品总盘

顶部显示七天产品 GMV、实际/预估到手、最终利润、利润率、动销件数及最近同步状态。主表每行代表一个产品，优先展示利润状态、七天趋势、动销 SKU 数、链接数和需要处理的异常。

### 产品详情

汇总该产品在全部店铺链接的七天表现，并用整齐的链接卡片横向比较成交均价、销量、到手金额、最终利润和状态。新增、暂停、下架、重新上线均保留历史。

### 链接详情

头部说明店铺、链接 ID、负责人、同步与结算状态。指标区区分 GMV、预估/实际到手、销量成本、链接费用和最终利润。

SKU 表默认一行一个 SKU，显示成交均价、销量、SKU GMV、产品成本、贡献利润和七天趋势。点击趋势后只展开当前 SKU 的七天明细。广告费和样品费在表格下方按链接填写，不混入 SKU 单行利润。

## 团队操作

- 产品成本支持一次填写并批量应用到该产品全部链接与 SKU。
- 广告费、样品费按链接当日填写，保存后链接与产品汇总立即更新。
- 同步按钮在模板阶段只演示状态变化；正式接入后触发本地同步服务。
- 每天北京时间 17:00 是计划同步时间；店铺时区和数据经营日必须同时展示。
- 同步失败、登录失效、结算延迟和 SKU 对账差异分别显示明确原因，不用同一个“异常”概括。

## 视觉与响应式

- 桌面端使用稳定的产品总盘、链接比较卡片和 SKU 表；数值按语义右对齐，状态与操作居中。
- 文案不出现孤字或不合理换行；按钮保持完整，紧凑信息使用 `white-space: nowrap`。
- 约 320px 窄屏改为卡片式 SKU 填写，页面整体不横向溢出；只有表格自身允许横向滚动。
- 颜色只表达利润、预估、已结算、警告和失败等状态，不使用无意义渐变或装饰性大标题。

## 模板验收

- 能从产品总盘进入产品详情，再进入单条链接。
- 同品多店多链接可比较，链接价格互不串改。
- 链接详情能看到最近七天成交均价和销量趋势。
- 页面明确区分 GMV、成交均价、预估到手、实际到手和最终利润。
- 产品成本可批量应用；广告费和样品费按链接填写。
- 已下架链接和停用 SKU 保留历史。
- 聚焦测试、完整检查、构建及桌面/窄屏浏览器回归通过。
