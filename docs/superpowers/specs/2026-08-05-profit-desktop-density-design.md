# 利润工作台桌面端高密度设计

## 目标

在不改变利润模型、页面结构和手机端可读性的前提下，将单条链接详情页的桌面端纵向占用压缩约 25%–30%，让运营人员在常见桌面屏幕中同时看到链接信息、核心指标、完整七日趋势和平台结算入口。

## 设计方案

- 仅在桌面断点（宽度大于 900px）启用高密度规则，现有平板和手机规则保持不变。
- 单条链接详情页的模块间距由 16px 收紧到 12px，主要内容模块内边距由 20px 收紧到 15px。
- 链接信息卡高度通过缩小上下内边距、产品标识和标题间距降低；操作按钮仍保持清晰可点。
- 五项核心指标保持一行，卡片最小高度由 104px 降至 78px；金额字号适度降低但仍为视觉主角。
- 七日趋势区减少标题、图例和画布留白；桌面主趋势图高度控制为 156px，日期轴和销量数据完整保留。
- SKU 展开趋势同步使用紧凑图表，但不改变数据和交互。
- 不使用页面整体缩放，不牺牲中文可读性，不改变利润计算、结算状态或数据录入逻辑。

## 验收标准

- 1440×900 桌面视口首屏可看到链接信息、五项核心指标、完整趋势图，并露出平台结算模块。
- 页面无横向溢出，金额、日期、图例和按钮不换行、不截断。
- 390×844 手机视口的现有模块尺寸和交互保持不变。
- 趋势图仍包含 7 个销量柱、1 条价格线和 2 个当日强调标记。
- 现有利润模板测试、项目完整检查和生产构建通过。

## 代码边界

本次只调整利润模板样式和对应的回归断言；不重构数据层、不更改模板文案、不触碰其他工作台模块。
